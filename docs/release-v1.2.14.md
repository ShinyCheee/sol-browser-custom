# Sol 1.2.14

- Sauvegardes : le service synchronise les mises à jour et les suppressions. Une sauvegarde en cours de téléchargement reste lisible après son remplacement sur le même appareil.
- Navigation : corrections de la gestion des onglets, des sessions et des extensions. Les fichiers téléchargés conservent leur provenance Internet pour les contrôles de sécurité Windows.
- Interface : corrections dans les réglages, les notes, les captures et l’inspecteur réseau.
- Distribution : paquets Microsoft Store allégés. La voix locale reste disponible sur Windows x64.
