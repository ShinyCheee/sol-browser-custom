# Sol Voice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Enable local Parakeet Ultra dictation and continuous turn-taking conversations with streamed spoken Sol AI responses.

**Architecture:** Reuse SolChat, its beUI VoiceOrb, ChatGPT sign-in and tool approvals. A persistent private stdio worker runs the exact Handy transcribe.cpp model and, after a real OpenAI compatibility probe, Piper if needed. Native capture and playback feed a cancellable per-window coordinator; models are downloaded and verified separately from bundled engine code.

**Tech Stack:** .NET 10/WinUI/WebView2, React/TypeScript, transcribe.cpp 0.4.1, embedded Python/Piper if the OAuth audio probe fails, native Windows audio.

**Spec:** docs/superpowers/specs/2026-11-06-sol-voice-design.md (approved, including explicit OpenAI-first probe).

## Global Constraints

- New and modified source files: 300 lines maximum; preserve CRLF.
- Development tools/caches/data: E:\dev; native tests offscreen at -9000 with disposable profiles.
- No CI/CD modification, push, tag or publication in this task.
- ChatGPT remains the reasoning engine; Parakeet Ultra Q8_0 is transcription only.
- Exact model: 740363168 bytes, SHA256 007a59761e9258779f189df396b50d12b83bb5b79e66df4b955c230d2f2a0a59.
- No personal microphone capture during automated checks; OpenAI probe uses a synthetic sentence.
- Conversation is explicitly started and never resumes after browser restart, error, close or stop.

## Review Focus

- Cancel/reopen while native inference is running: stale output must never send a command.
- Several windows/profiles competing for the microphone or model installation: one owner, no corruption.
- Markdown fences/links split across network fragments: no code, duplicate phrases or raw URLs spoken.
- Interrupted AI response after audio has begun: discard queued audio and keep visible error/history accurate.
- Missing devices, unsupported CPU/architecture, Store packaging: useful errors without browser startup failure.
